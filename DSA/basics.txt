=> Algorithm
    it is a set of rules or instructions to accomplish the task
    1. recursive
    2. searching tech
    3. sorting tech
    4. divide and conqure
    5. brute force
    6. dynamic programming
    7. back tracking Algorithm


=> common opertaions in DS 
    - insertion:
        it is used to add new element to the respective DS
    - deletion:
        it is used to remove the existing element present in a respective DS
    - searching:
        it is used to search for specific element in DS
    - sorting:
        it is used to rearrange the elements either in accending or decending order
    - traversing:
        it is used to fetch each element present in DS
    - merging:
        it is used to merge two DS
